# Metrica EPTS Tactical Radar Web Client

This directory contains the Vite + React single-page application for the **Metrica EPTS Tactical Radar Visualizer**.

> **Note**: This application is currently a **prototype**. In the target production release, tracking data will be ingested in real time from a live video source via a dedicated Computer Vision pipeline, replacing offline pre-tracked datasets from Metrica Nexus.

## Development Setup

```bash
# Install dependencies
npm install

# Run Vite dev server
npm run dev
```
